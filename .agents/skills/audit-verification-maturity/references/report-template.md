# 审计输出模板

按用户需要压缩措辞，保留事实、边界与优先建议。不要照填没有证据的字段，也不要为填表编造数据。

## 1. 范围和结论

审计对象：项目/PR/提交/模块；时间；当前revision与未提交变化；证据对应revision；已读取范围；环境与访问限制。未指定时声明采用的范围。

先用两三句说明已能支持哪些关键承诺，以及哪个风险目前最缺证据。说明“本次所执行检查通过”所指的集合。

## 4. 优先建议（通常3–5项）

### G01：具体缺口

- 风险：在什么条件下，什么承诺可能失效，影响是什么。
- 依据：E01等证据及关键位置，区分确认缺失和待核实。
- 建议：最小补强措施，复用哪些已有能力。
- 完成条件：可观察结果、检查入口和产物；适用时说明应被检出的故意缺陷。
- 优先级：P0/P1/P2或“待核实后定级”；成本量级与置信度。

每项须能帮助决定下一步；“补更多单测”“提高覆盖率”“全部上形式化”等泛建议不合格。不把这些建议描述为已经获准实施。
