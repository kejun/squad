BT_L19 与 BT_L22 在实现基线和本次运行均失败。容器中的原生沙箱探针报告 `Required OS namespaces are unavailable`，两个场景仍按原配置执行。浏览器验收使用真实 HTTP、SQLite 和宿主子进程，模型响应来自受控本地提供方。

浏览器确认三个待续办请求跨刷新保存，两条命令共用会话授权并串行运行。390 像素视口用键盘撤销后，后续命令重新要求批准。重启保留已结算效果并产生新批准。综合与独立检查各执行一次。新版报告检查期间保留原发布版，通过后发布修订，原消息及历史入口仍打开原报告。两个不同 Bot 的实际命令可复用同一匹配会话。

隔离检查和后台讨论的失败记录显示明确的续办拒绝原因。此边界保护原隔离范围，常规宿主续办沿用单次或任务会话批准。
