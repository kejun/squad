基线：6134a0c；分支 codex/kej-112-tool-guidance。Linear 对应项目名称为 sqaud。

## 核查与方案

先创建 EARS issue，再独立核查现有实现与需求。现有 KEJ-109 提供人工目录、KEJ-110 提供任务内方法共享、KEJ-111 提供有界 Web 失败恢复；本期只增加当前工作相关的候选投影、真实 CLI 失败分类和重复失败请求守卫。推荐不是授权、安装/认证证明或资料获取证据。

可执行中文场景 BT_L117–BT_L124 位于 features/53_tool_guidance.feature；状态入口 README「状态模型」，细化图为 docs/state-diagrams.md「工具推荐与失败纠正」。先完成场景与图，再进入纯模型阶段，模型通过后才接入 runtime/runner/adapter。

相同键保留命令和 argv 顺序，将 cwd 缺省为 .、execution 缺省为 sandbox、skillId 缺省为 null，不比较 reason/timeout。不宣称路径别名等价。仅明确可诊断的失败计数，未知业务失败不受该新限制；原普通额度与截止时间仍限制全部调用。

候选匹配是确定的词项匹配，非语义模型。从全部已加载元数据检索，分别报告技能源扫描不完整与匹配条目省略。空目录不会自动扫描 PATH；可继续显式 discoverHost 或 listSkills。帮助及修正通过原 runCli，宿主命令继续等待原审批。
