## 真实恢复及权限边界

六个活动阶段均执行到期、续窗、交付、检查、complete 的真实模型轨迹，另验证未开始分片、已领取解析、未完成协助、已保存答复、未知物理效果与通用 CONTINUE 入口。续窗保留 epoch、原成果、计费、分片及回执，旧宿主会话授权撤销，未知效果仍须独立结算。跳过旧命令只省略其范围；结束窗口才冻结任务。

stdin 输入是工作区文件的私有只读字节快照。固定检查只使用运行时脱敏后保存的实际 executable/argv/cwd/environmentHash 和 stdin 指纹；内部原动作快照不进入模型材料。普通 owner 的 `validationInputsChanged` 为 null，不把未经测量的 false 当成未修改证明。相同路径修正输入字节后可重试，相同实测输入和环境仍受重复失败限制；固定验证命令不能附加 stdin。

旧固定 CLI 检查引用没有新增的调用身份快照时，会明确拒绝 `CHECK_EVIDENCE_CHANGED`。需要重新提交候选形成新固定边界，不会补造旧输入指纹或沿用为已验证的新证据。这是升级中的保证边界变化。

## 实机证据与适用范围

自动目录在本机发现 1671 个命令，完整原始目录约 783KB、扫描约 1.3 秒。带两环境观测与接口的完整模型请求约 2.54MB；首个真实模型请求使用约 71 万输入 token。服务通过后台快照避免每次决策扫描，保留全部条目；全量策略仍有实际上下文成本。包级摘要、资料来源、未知用途与同名 wrapper 的不同说明均保留，不能借其他安装位置的 man 说明推断能力。

使用用户提供的 `deepseek-v4.1-flash` 与 API 地址运行了真实模型 → WorkRunner → SQLite → 原生沙盒 → tesseract → 固定检查。最终任务 34,751ms、4 次模型请求、2 次 OCR 调用，首轮直接选择 `tesseract stdin stdout`，两次输出均为 `HELLO`，保存 OCR.md 并以 complete 结束。未请求沙盒失败作为宿主前置，也未使用脚本替代真实模型回复。全部请求、响应、回执、源码指纹及凭据扫描记录保留在 `/workspace/work/squad-window-experience/live-final/`。

初次真实任务的 partial 原件保留在相邻 `live/`。当时固定材料缺少实际调用和输入身份，且测试配置输出预算为 6000 token；最终复测补齐证据并使用 16000 token。因此这不是单一因素的准确率或因果性能研究，也不声称所有 OCR 工具都支持 stdin。内置具体例子只对应本轮实际运行的 tesseract。
