基线：origin/main 5b8c596；独立分支 fix/kej-109-cli-discovery。需求：https://linear.app/kejunz/issue/KEJ-109

## 方案与边界

复用现有持久化本地操作、技能快照和独立检查协议。宿主以受信 JSON 配置提供 CLI 目录；不扫描凭据、不自动执行帮助、不安装软件。目录按用途和域名检索，返回帮助参数及环境要求。技能查询支持跨名称、描述、来源、兼容要求的全部关键词匹配。目录和技能续页游标绑定归一化查询与目录版本，旧数字游标返回明确错误。

成员在每次模型请求前读取同任务当前目标与轮次中其他成员的成功调用参数及回执标识，不复制资料正文或批准。最多10条，每条命令最多4000序列化字符，已登记凭据经运行时脱敏；不重复附带无关技能绑定。并发首轮尚无成功回执时仍可能同时探路，不新增全局队列或命令缓存。实际读取继续各自保存、批准、领取和结算。

交付补试保存合法验收项、已知来源、引用长度和匹配前缀的来源位置，保持公开固定错误码，不保存被拒的模型引文或未知来源ID。补试收到原候选、原来源及定位信息；仍须完整独立检查和逐字校验。技术补试耗尽保留报告与成功工具回执，并标记交付检查未完成。

状态图：docs/state-diagrams.md 的“宿主命令目录与技能检索”“同任务 CLI 调用经验投影”“交付检查技术补试诊断”。中文契约：BT_L77–L87、BT_F29–F31，未新增验收排除项或单测断言。
