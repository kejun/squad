## 方案与范围

已复现 Web 工具异常不回灌而直接终止工作，以及8片7失败后负责人补齐仍被历史 incomplete 字符串锁为 partial。本期统一有界 Web 失败反馈，并增加负责人提交的结构化分片恢复声明、完整来源机械门禁和独立逐片验收，保留历史失败与当前候选发布隔离。任务内成功方法共享沿用既有实现；跨任务经验库和通用自动工具规划留给后续独立迭代。

可恢复工具失败最多2次/工作，按工作尝试和请求身份幂等持久化；下一次模型和工具请求仍按普通额度、后继预留与原期限授权。停止、过期、权限、预算和未知效果不是可绕过的失败。

首期分片恢复复用现有完整成功 CLI 回执（exitCode=0、正文完整、捕获哈希可用），覆盖本次 yuque 补齐场景；Web内存返回、普通自述和无完整回执的读取不升级为恢复证据。分片恢复使用当前负责人、同一目标/轮次的完整成功回执及当前候选的逐片验收；普通独立成员评审不能由负责人替代。旧分片 failed/partial/timeout 与原结果不改写。来源错误、只补齐部分或检查不通过仍不得 complete；恢复证明不因重启、重复事件和候选变化被移用。
