# 归档会话强制删除

原始要求：删除归档会话就是强制删除，不需要核对。

## EARS 与核查

- FDEL-01：当用户删除已归档会话时，系统应直接删除该会话数据并从列表移除，不要求二次确认或核对旧操作。
- FDEL-02：如果该会话存在未决操作或资源锁，系统应终止已知执行、释放该会话的锁，允许其他会话继续；不得把未知外部效果标记为成功或回滚。
- FDEL-03：在数据已删除而文件清理尚未完成时，系统应持久保存后台清理意图并自动恢复、重试，不恢复会话或要求用户核对。
- FDEL-04：当处理重复请求、迟到回调或重启时，系统应保持已删除状态；其他会话、共享工程、技能和账号文件应保留。
- FDEL-05：如果请求跨域、目标不存在或目标已恢复为未归档，系统应拒绝删除；旧归档版本号不得阻止删除仍处于归档状态的目标。

核查：与原文一致。强制删除覆盖用户可见的旧安全删除流程；只复用既有独立删除作业、墓碑、运行文件所有权和事务。未知外部效果不再构成人类门，但路径边界和其他会话隔离保留。不存在依赖用户补充信息的分支。场景 BT_Y162–Y167；旧版删除快照保留可恢复性。

## 验证边界

先验证真实 `roomDeletionMachine` 的强制删除、旧作业升级、重启、迟到结果及技术失败轨迹，再接入 SQLite、HTTP、真实文件与浏览器。强制删除不承诺撤销已发生的外部业务效果。后台文件清理遇到权限或目录边界错误时自动重试，会话不重新出现。
