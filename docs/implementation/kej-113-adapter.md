## 分工与模型前置

本变更不新增适配器自主管理的业务调度。任务生命周期、操作意图和恢复决策仍归真实 `taskMachine`；TeamEngine 领取校验后，WorkRunner 才能执行。领取后启动失效必须以模型支持的未启动／失败事件返回，由对应角色恢复策略决定后继，不能仅 `SETTLE` 后丢失继续路径。

网页 `tracedScope` 保留 Runner 的实时 getter 和 `recordToolFailure`。读取建议随当前工作、权限和真实回执变化，不能在包装时固定为过期快照。实际模型仍只能从持久化意图请求工具；记录失败不授权新执行，不绕过既有 `CONSUME`、`RECORD_TOOL_FAILURE` 和输出修复预算。

CLI 目录应分别报告未配置、配置为空和无匹配。入口存在性、宿主授权、账号认证状态只依据真实发现、明确用户决策或可信工具回执；没有这些证据时报告未知。建议保留已登记入口及非敏感前提，但不得推荐已核实不存在或未获授权的入口为当前可用，不执行额外探测或读取凭据来生成建议。

内容语义复用证据模块的可信资源观察：资源身份、校验器身份和版本、正文状态、内容哈希与捕获时间绑定原操作和工作身份。无可信校验器的任意 CLI 保留进程层成功，内容层保持未知；登录页、空壳、错误资源、部分内容不升级为完整正文成功方法。具体类型与资源匹配由证据模块和根代理统一，本文不另造 stdout 自证接口。

技能服务 408、429、5xx 或传输中断形成脱敏且可诊断的暂时失败。权限关闭、401／403、停止、陈旧身份、到期和额度耗尽不重试。有限重试沿用任务模型的恢复和成本规则；期限或恢复机会耗尽后交由统一降级策略，不能在适配器内发起额外无授权请求。

关闭时分别管理工作 Promise、取消回调、授权等待及物理清理责任。对已真实结算的原执行，不因无意义的远端取消回调阻塞关闭；对仍有物理效果的操作，须先持久移交核对责任并保留真实冲突资源。数据库不可写时不得声称移交或终态已持久化，必须保留宿主故障出口。

## 已接入行为及集成验证

Runner 通过可信 `engine.executionNotStarted` 返回启动拒绝，不再用一般 `SETTLE` 丢失后继。技能发现的 408、429、5xx 和传输异常成为脱敏暂时失败，沿原预算有限恢复；401／403、功能撤权、停止、旧身份和到期保持拒绝。目录返回 `configuration.state` 与 `matchState`，Runner 仅从真实发现、当前工作登记调用和宿主取得凭证投影安装／认证／授权事实。一次具体调用被拒绝不会泛化为其他任务或其他参数已经获得或失去授权。

网页包装由根代理完整转发实时工具 getter 和失败反馈。Runner 在已保存 `LOCAL_RESULT` 后取稳定原操作，经 Runtime 已登记读取器生成并保存可信取得观察；CLI stdout 自带的取得字段不获得权限。生产网页工具保留受 `maxBytes` 约束的全页宿主捕获，模型仍读取分页窗口；Runner 把实际请求、最终 URL、状态、全页正文和哈希绑定可信取得观察。未提供全页捕获的第三方工具仍保守按窗口完整性处理，不拼接跨请求版本。

运行器提供 `abortExecutions(roomId?,taskId?)`、`drainExecutions(graceMs)` 和 `detachExecutions()`：取消信号不依赖数据库写入；drain 包括独立取消回调并有界返回；宿主持久接管后 detach 阻止迟到回调读取、写入或记录已关闭引擎。网页服务按全部历史任务管理宽限、批准等待、原执行与取消回调，过界后接管并退休回调。

## 原结果与取得观察之间的恢复边界
